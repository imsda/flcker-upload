NAS Network Share (SMB)

Connects straight to a Ugreen, Synology, QNAP, TrueNAS or Windows share. Nothing needs to be mounted on this server. Use a NAS account with read access to the share; it needs read/write access if you want files moved after upload.

You can paste a full address such as \\192.168.1.20\Photos\Events or smb://nas/Photos into the server field. Move-to folders are paths inside the same share and only apply when General → After successful upload is set to move.

Folder Mounted on This Server
